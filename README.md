# Thiên Đạo AI Game Studio

Website tĩnh miễn phí dành cho thiết kế asset 2D/2.5D.

## Sử dụng
- Mở trang chủ index.html, chọn **Mở xưởng sáng tạo**.
- Pixel Studio: bút/tẩy, hoàn tác, PNG và lưu trên trình duyệt.
- Map Studio: bản đồ 30×18, đặt địa hình và xuất JSON/PNG.
- HD Art: nhập ảnh, chỉnh kích thước, xuất PNG.
- AI Studio: giao diện minh họa, cần backend và dịch vụ AI thực tế.

## Đưa lên mạng miễn phí với GitHub Pages
1. Repository Settings → General → Danger Zone → Change repository visibility → **Public**. Chỉ làm khi bạn chấp nhận công khai mã nguồn.
2. Settings → Pages → Build and deployment → Deploy from a branch.
3. Branch **main**, folder **/(root)** → Save.
4. Mở https://jinhwangdo1-hash.github.io/web/ sau khi GitHub báo triển khai thành công.

## Codex
Yêu cầu Codex mở rộng map layer/tileset và assets HD, bảo mật API key phía backend, thêm xác thực và kiểm thử. Không đưa khóa bí mật vào GitHub Pages.
